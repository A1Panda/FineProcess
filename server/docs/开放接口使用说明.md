# 开放接口使用说明

本文档面向**快工单工序细化管理系统**（主系统）对外开放的数据接口，供 AstrBot 机器人插件等外部服务调用。

## 1. 总览

| 项        | 说明                                                                       |
| -------- | ------------------------------------------------------------------------ |
| Base URL | `http://localhost:3001/api/report-data`（生产环境为实际部署地址）                     |
| 鉴权方式     | Header `X-API-Key`，值为配置项 `PLUGIN_API_KEY`（`.env` 中 `PLUGIN_API_KEY=...`） |
| 数据格式     | 请求与响应均为 JSON                                                             |
| 数据源      | 主系统通过快工单 OpenAPI（`https://api.kgd.ltd`）实时拉取或读本地缓存                        |

### 1.1 鉴权

所有接口统一校验请求头：

```
X-API-Key: 7aa6aa6cacc3c3574873f1c5f95b001e4094ebfe2bcce36ac71553ade1385c74
```

- 缺少或错误的 Key 返回 `403 Forbidden`。
- 该 Key 由服务端 `.env` 中的 `PLUGIN_API_KEY` 决定，属机器凭证（无状态、不过期），注意保管。

### 1.2 接口清单

| 方法  | 路径                             | 用途              |
| --- | ------------------------------ | --------------- |
| GET | `/api/report-data/day-reports` | 指定日期报工明细        |
| GET | `/api/report-data/tasks`       | 按状态查任务列表        |
| GET | `/api/report-data/task`        | 按加工单号+工序查合并任务详情 |
| GET | `/api/report-data/users`       | 用户列表（含部门路径）     |
| GET | `/api/report-data/bills`       | 加工单交期映射         |
| GET | `/api/report-data/bill-status` | 加工单列表+状态+工序进度链  |
| GET | `/api/report-data/goods`       | 商品列表（含扩展字段）     |
| GET | `/api/report-data/crafts`      | 工序列表             |
| GET | `/api/report-data/produce-bills` | 加工单列表（实时）     |
| POST | `/api/report-data/bill`        | 编辑加工单（写操作）     |
| POST | `/api/report-data/crafts/add`  | 工序新增（写操作）       |
| POST | `/api/report-data/crafts/edit` | 工序编辑（写操作）       |
| POST | `/api/report-data/goods/add`   | 商品新增（写操作）       |
| POST | `/api/report-data/goods/edit`  | 商品编辑（写操作）       |
| POST | `/api/report-data/produce-bills/add` | 加工单新增（写操作）   |
| POST | `/api/report-data/produce-bills/status` | 加工单状态修改（写操作） |
| POST | `/api/report-data/tasks/status` | 生产任务状态修改（写操作） |

### 1.3 错误约定

| HTTP 状态 | 含义                        |
| ------- | ------------------------- |
| 200     | 成功，返回 JSON 数据             |
| 403     | 鉴权失败（`X-API-Key` 缺失或不匹配）  |
| 500     | 服务内部错误（如快工单 OpenAPI 校验失败或暂不可用） |

> 注：除 `bills` 外的实时拉取接口会直接依赖快工单 OpenAPI，网络异常时可能报 500 或空数组；`bill-status` / `bills` 读本地缓存，查询前会自动触发一次即时同步（首次调用可能稍慢），同步失败时继续返回旧缓存。

## 2. 报工明细

### GET `/api/report-data/day-reports`

按日期获取当日所有报工记录（按 `created_at` 归属日期）。

**Query 参数**

| 参数    | 必填 | 类型     | 说明                                |
| ----- | -- | ------ | --------------------------------- |
| `day` | 是  | string | 日期，格式 `YYYY-MM-DD`，如 `2026-08-12` |

**返回**：`Array<ReportRecord>`

| 字段               | 类型             | 说明                    |
| ---------------- | -------------- | --------------------- |
| `billCode`       | string         | 加工单号                  |
| `craftName`      | string         | 工序名称                  |
| `goodsName`      | string         | 商品名称                  |
| `goodsStandard`  | string         | 商品规格                  |
| `deliveryDate`   | string \| null | 交期（`YYYY-MM-DD`，可能为空） |
| `htNo`           | string \| null | 扩展字段「HT图号」            |
| `reportUserName` | string         | 报工人姓名                 |
| `validNum`       | string         | 良品数量                  |
| `wasteNum`       | string         | 不良数量                  |
| `reportNum`      | string         | 报工数量                  |
| `workingMinutes` | number         | 工时（分钟）                |
| `priceModeName`  | string         | 单价模式名称                |

**示例**

```
GET /api/report-data/day-reports?day=2026-08-12
```

```powershell
Invoke-RestMethod -Uri "http://localhost:3001/api/report-data/day-reports?day=2026-08-12" `
  -Headers @{ "X-API-Key" = "7aa6aa6cacc3c3574873f1c5f95b001e4094ebfe2bcce36ac71553ade1385c74" }
```

```json
[
  {
    "billCode": "20260801-001",
    "craftName": "激光下料",
    "goodsName": "石墨板",
    "goodsStandard": "500x500x20",
    "deliveryDate": "2026-08-15",
    "htNo": "HT2026-0100",
    "reportUserName": "张三",
    "validNum": "80",
    "wasteNum": "2",
    "reportNum": "82",
    "workingMinutes": 120,
    "priceModeName": "按工时"
  }
]
```

> 说明：报工接口无时间戳字段，本接口按 `day` 拼接 `created_at` 时间窗口实时拉取，每日数据不可缓存、必须实时请求。

## 3. 任务列表

### GET `/api/report-data/tasks`

按任务状态查询生产任务列表。

**返回**：`Array<Task>`

| 字段                    | 类型             | 说明                                     |
| --------------------- | -------------- | -------------------------------------- |
| `code`                | string         | 加工单号                                   |
| `ht`                  | string         | 扩展字段「HT图号」（可能为空）                       |
| `craft`               | string         | 工序名称                                   |
| `goods`               | string         | 商品名称                                   |
| `standard`            | string         | 商品规格                                   |
| `num`                 | string         | 计划数                                    |

| `startTime`           | string \| null | 开始时间（取 `start_time`，无则回退 `created_at`） |

| `produceLineNames`    | string         | 生产线名称                                  |
| `reportableUserNames` | string         | 可报工人姓名                                 |

## 4. 任务详情（合并）

### GET `/api/report-data/task`

按「加工单号 + 工序名称」精确查询，多任务并存时合并数量并按优先级取状态（进行中 > 已完成 > 其他）。

**Query 参数**

| 参数      | 必填 | 类型     | 说明                |
| ------- | -- | ------ | ----------------- |
| `code`  | 是  | string | 加工单号，**需 URL 编码** |
| `craft` | 是  | string | 工序名称，**需 URL 编码** |

**返回**：`TaskDetail \| null`（查无返回 `null`）

| 字段                      | 类型     | 说明               |
| ----------------------- | ------ | ---------------- |
| `num`                   | number | 计划数（合并求和）        |
| `valid_num`             | number | 良品数（合并求和）        |
| `waste_num`             | number | 不良数（合并求和）        |
| `status_name`           | string | 状态名称（按优先级取最高的）   |
| `ht`                    | string | HT图号（多值用「、」连接）   |
| `produce_line_names`    | string | 生产线（多值去重合并）      |
| `reportable_user_names` | string | 可报工人（多值去重合并）     |
| `delivery_date`         | string | 交期（`YYYY-MM-DD`） |

**示例**

```
GET /api/report-data/task?code=20260801-001&craft=%E6%BF%80%E5%85%89%E4%B8%8B%E6%96%99
```

```powershell
$code = [uri]::EscapeDataString("20260801-001")
$craft = [uri]::EscapeDataString("激光下料")
$url = "http://localhost:3001/api/report-data/task?code=$code&craft=$craft"
Invoke-RestMethod -Uri $url -Headers @{ "X-API-Key" = "7aa6aa6cacc3c3574873f1c5f95b001e4094ebfe2bcce36ac71553ade1385c74" }
```

```json
{
  "num": 100,
  "valid_num": 80,
  "waste_num": 2,
  "status_name": "进行中",
  "ht": "HT2026-0100",
  "produce_line_names": "一号线",
  "reportable_user_names": "张三、李四",
  "delivery_date": "2026-08-15"
}
```

> 注意：`code` / `craft` 含中文或特殊字符时必须做 `encodeURIComponent` 编码，否则可能匹配失败。

获取全部用户及部门路径（供插件建立产线/部门索引）。

**Query 参数**：无

| --------------------- | ------ | --------------- |
| `name`                | string | 登录名             |
| `realName`            | string | 真实姓名            |
| `departmentPathNames` | string | 部门路径（如「一车间/南线」） |

**示例**

```
GET /api/report-data/users
```

```json
[
  { "name": "zhangsan", "realName": "张三", "departmentPathNames": "一车间/南线" }
]
```

## 6. 加工单交期

### GET `/api/report-data/bills`

按加工单号批量查询交期映射。读本地缓存，查询前自动触发一次即时同步（保证尽量新鲜）。

**Query 参数**

| 参数      | 必填 | 类型     | 说明                      |
| ------- | -- | ------ | ----------------------- |
| `codes` | 是  | string | 加工单号，逗号分隔传多个。为空时返回 `{}` |

**返回**：`Record<string, string>`，`{ 加工单号: "YYYY-MM-DD" }`（未查到或无交期的单不出现在结果中）

**示例**

```
GET /api/report-data/bills?codes=20260801-001,20260802-002
```

```json
{
  "20260801-001": "2026-08-15",
  "20260802-002": "2026-08-18"
}
```

> 注意：`codes` 中应使用 URL 编码后的加工单号（含 `-` 等字符时建议编码）。

## 7. 加工单进行状态

### GET `/api/report-data/bill-status`

获取加工单列表 + 整单状态 + 逐工序进度链。读本地缓存，查询前自动触发一次即时同步。按交期从早到晚排序，无交期排最后。

**Query 参数**：无

**返回**：`Array<BillStatus>`

| 字段              | 类型             | 说明                                  |
| --------------- | -------------- | ----------------------------------- |
| `code`          | string         | 加工单号                                |
| `htNo`          | string         | HT图号                                |
| `goodsName`     | string         | 商品名称                                |
| `goodsSpec`     | string         | 商品规格                                |
| `num`           | string         | 计划数                                 |
| `unitName`      | string         | 单位名称                                |
| `status`        | number         | 加工单状态：`1`=未开始、`2`=进行中、`3`=完成、`4`=取消 |
| `statusName`    | string         | 状态名称                                |
| `deliveryDate`  | string \| null | 交期（`YYYY-MM-DD`）                    |
| `craftProgress` | array          | 工序进度链（同单按工艺顺序排列）                    |

`craftProgress[]` 每项：

| 字段           | 类型     | 说明                          |
| ------------ | ------ | --------------------------- |
| `craftName`  | string | 工序名称                        |
| `status`     | number | 任务状态码（1 未开始 / 2 进行中 / 3 完成） |
| `statusName` | string | 状态名称                        |
| `percent`    | number | 完成百分比 = (良品+不良)/计划数，封顶 100  |
| `num`        | number | 计划数                         |
| `validNum`   | number | 良品数                         |
| `wasteNum`   | number | 不良数                         |

**示例**

```
GET /api/report-data/bill-status
```

```json
[
  {
    "code": "20260801-001",
    "htNo": "HT2026-0100",
    "goodsName": "石墨板",
    "goodsSpec": "500x500x20",
    "num": "100",
    "unitName": "件",
    "status": 2,
    "statusName": "进行中",
    "deliveryDate": "2026-08-15",
    "craftProgress": [
      { "craftName": "激光下料", "status": 2, "statusName": "进行中", "percent": 82, "num": 100, "validNum": 80, "wasteNum": 2 },
      { "craftName": "精加工", "status": 1, "statusName": "未开始", "percent": 0, "num": 100, "validNum": 0, "wasteNum": 0 }
    ]
  }
]
```

> 渲染约定（插件侧）：`status=1`（未开始）展示「未编程」；`status=2` 起逐工序展示进度 chip（percent / 良品 / 计划）。
> 注意：本接口全量返回所有加工单（含已完成/已取消的历史单），渲染成图片时建议只取 `status ∈ {1, 2}` 的行，避免单图超高度上限。

## 8. 商品列表

### GET `/api/report-data/goods`

商品列表（实时拉取快工单 `/open_api/goods/list`），支持关键字过滤与扩展字段透传。

**Query 参数**

| 参数 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `keyword` | 否 | string | 关键字，按商品名/编号/规格模糊查询。省略返回全部 |
| `updatedAtStart` | 否 | string | 更新时间起，格式 `YYYY-MM-DD HH:mm:ss`（空格需 URL 编码为 `%20`） |
| `updatedAtEnd` | 否 | string | 更新时间止，格式 `YYYY-MM-DD HH:mm:ss`（空格需 URL 编码为 `%20`） |
| `supplierName` | 否 | string | 供应商名称/简拼（精确匹配） |
| `createUserName` | 否 | string | 创建人名称/简拼（精确匹配） |
| `categoryName` | 否 | string | 商品分类名称（精确匹配，需传快工单侧真实的分类名称） |
| `source` | 否 | integer | 商品来源：1=自产，2=外协加工，3=外购 |
| `isEnable` | 否 | integer | 是否启用：1=启用，2=未启用（不传为全部） |

> 提示：`supplierName` / `createUserName` / `categoryName` 为快工单侧**精确匹配**，实测传入与返回的分类路径（`categoryPathNames`）不完全一致时可能返回空，请以快工单系统内的实际名称/分类配置为准。

**返回**：`Array<Goods>`

| 字段                  | 类型             | 说明                                                                   |
| ------------------- | -------------- | -------------------------------------------------------------------- |
| `id`                | number         | 商品 ID                                                                |
| `code`              | string         | 商品编号                                                                 |
| `name`              | string         | 商品名称                                                                 |
| `standard`          | string         | 规格                                                                   |
| `categoryPathNames` | string         | 分类路径                                                                 |
| `source`            | number         | 来源                                                                   |
| `sourceName`        | string         | 来源名称                                                                 |
| `unitName`          | string         | 单位名称                                                                 |
| `updatedAt`         | string \| null | 更新时间                                                                 |
| `fieldValueList`    | array          | 扩展字段数组，`[{ name, value }]`（如 `[{ "name": "HT图号", "value": "..." }]`） |
| `fieldValues`       | object         | 扩展字段 key-value 映射，可直接 `fieldValues['HT图号']` 取值                       |

**示例**

```
GET /api/report-data/goods?keyword=%E7%9F%B3%E5%A2%A8
```

```powershell
$kw = [uri]::EscapeDataString("石墨")
Invoke-RestMethod -Uri "http://localhost:3001/api/report-data/goods?keyword=$kw" `
  -Headers @{ "X-API-Key" = "7aa6aa6cacc3c3574873f1c5f95b001e4094ebfe2bcce36ac71553ade1385c74" }
```

```json
[
  {
    "id": 12345,
    "code": "SM-001",
    "name": "石墨板",
    "standard": "500x500x20",
    "categoryPathNames": "原材料/石墨",
    "source": 1,
    "sourceName": "自建",
    "unitName": "件",
    "updatedAt": "2026-08-10 09:00:00",
    "fieldValueList": [ { "name": "HT图号", "value": "HT2026-0100" } ],
    "fieldValues": { "HT图号": "HT2026-0100" }
  }
]
```

## 9. 编辑加工单

### POST `/api/report-data/bill`

编辑快工单系统内的加工单信息（透传快工单 `/open_api/produce_bill/edit`，字段校验由快工单侧完成）。

**Body（JSON）参数**

| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `id` | 是 | integer | 加工单 ID |
| `code` | 否 | string | 加工单编号，为空会生成新的加工单编号 |
| `num` | 是 | string | 计划数 |
| `delivery_date` | 否 | string | 交货日期 |
| `priority_name` | 否 | string | 加工单优先级 |
| `start_produce_date` | 否 | string | 计划开始日期 |
| `end_produce_date` | 否 | string | 计划结束日期 |
| `remark` | 否 | string | 备注 |
| `craft_list` | 是 | array | 工序列表（见下表） |
| `fieldValueList` | 否 | array | 扩展字段，`[{ name, value }]` |
| `attachments` | 否 | array | 附件列表 |

`craft_list[]` 每项：

| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `id` | 否 | string | 生产任务 ID，更新已有工序时必传，否则视为新增 |
| `pub_craft_id` | 是 | integer | 工序 ID |
| `from_unit_num` | 是 | integer | 单位关系原始单位数量（商品/计划数单位） |
| `to_unit_num` | 是 | integer | 单位关系目标单位数量（工序单位） |
| `unit_money` | 是 | number | 工资单价 |
| `waste_item_ids` | 是 | array[int] | 不良品项（字段必须存在） |
| `need_quality` | 否 | integer | 是否需要质检：1=是，2=否（需质检时不允许外协） |
| `standard_working_seconds` | 否 | string | 标准工时（秒） |
| `plan_start` | 否 | string | 计划开始 |
| `plan_end` | 否 | string | 计划结束 |
| `price_mode` | 是 | integer | 计价方式：1=计件，2=计时 |
| `need_scrap_rework` | 是 | integer | 是否需要报废/返工：1=是，2=否 |
| `need_outsource` | 是 | integer | 是否需要外协：1=是，2=否（外协时不允许质检、不良品不允许报废） |
| `remark` | 否 | string | 备注 |
| `device_ids` | 是 | array[string] | 机台 id 列表（字段必须存在） |
| `quality_type` | 是 | integer | 质检类型：1=全检，2=抽检，3=无需质检 |
| `inspection_scheme_name` | 否 | string | `quality_type=2` 时必填，抽检方案名称 |

**返回**

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | integer | 加工单 ID |
| `code` | string | 加工单号 |

**示例**

```
POST /api/report-data/bill
```

```powershell
$body = @{
  id = 192662
  code = "测试新增加工单"
  num = "50"
  delivery_date = "2025-11-1"
  priority_name = "中"
  start_produce_date = "2025-11-1"
  end_produce_date = "2025-11-29"
  remark = "测试新增加工单"
  craft_list = @(
    @{
      id = "17114"
      pub_craft_id = 64679
      from_unit_num = 1
      to_unit_num = 1
      unit_money = 50
      waste_item_ids = @()
      need_quality = 1
```

## 12. 注意事项汇总

1. **鉴权**：所有请求必须带 `X-API-Key` 头，缺失或不匹配返回 403。
2. **实时 vs 缓存**：`day-reports` / `tasks` / `task` / `users` / `goods` 实时拉取快工单 OpenAPI；`bills` / `bill-status` 读本地缓存，查询前触发即时同步（首次稍慢，同步失败回退旧缓存）。
3. **URL 编码**：`task` 的 `code` / `craft`、`goods` 的 `keyword` 含中文时务必编码。
4. **多值参数**：`tasks?status=1,2`、`bills?codes=a,b` 用英文逗号分隔。
5. **日期格式**：`day` 严格为 `YYYY-MM-DD`。
6. **数据上限**：实时拉取单接口上限 10000 条（分页 100 条/页、并发 6）。
7. **渲染注意**：`bill-status` 全量返回，图片渲染时建议过滤 `status ∈ {1,2}` 防超 Chrome 单图高度上限。
8. **写操作谨慎**：`bill` 为 POST 编辑接口，会真实修改快工单数据；字段校验失败时返回 500 + 快工单错误信息。
