# 开放接口使用说明

本文档面向**快工单工序细化管理系统**（主系统）对外开放的统一接口，供 AstrBot 机器人插件、「快工单合同导入建单」浏览器扩展、产品编码管理系统等外部服务调用。机器人插件消费只读数据（GET 系列），浏览器扩展通过 POST 系列透传快工单取数/传数（登录由主系统统一负责）。

## 1. 总览

| 项        | 说明                                                                       |
| -------- | ------------------------------------------------------------------------ |
| Base URL | `http://localhost:3001/api/report-data`（生产环境为实际部署地址）                     |
| 鉴权方式     | Header `X-API-Key`，值为配置项 `PLUGIN_API_KEY`（`.env` 中 `PLUGIN_API_KEY=...`） |
| 数据格式     | 请求与响应均为 JSON                                                             |
| 响应格式     | 成功 `{ "success": true, "data": ... }`；失败 `{ "success": false, "msg": "..." }`（与快工单 OpenAPI 风格一致） |
| 数据源      | 主系统通过快工单 OpenAPI（`https://api.kgd.ltd`）实时拉取或读本地缓存                        |

### 1.1 鉴权

所有接口统一校验请求头：

```
X-API-Key: 7aa6aa6cacc3c3574873f1c5f95b001e4094ebfe2bcce36ac71553ade1385c74
```

- 缺少或错误的 Key 返回 `401 Unauthorized`（`message: 开放接口凭证错误`）。
- 该 Key 由服务端 `.env` 中的 `PLUGIN_API_KEY` 决定，属机器凭证（无状态、不过期），注意保管。

### 1.3 错误约定

| HTTP 状态 | 含义                        |
| ------- | ------------------------- |
| 200     | 请求已处理。业务成功看 `success` 字段：`true` 取 `data`，`false` 看 `msg` |
| 401     | 鉴权失败（`X-API-Key` 缺失或不匹配），响应为标准错误体 `{ statusCode, message, error }`，非 `{success}` 包装 |
| 500     | 服务内部错误（如快工单 OpenAPI 校验失败或暂不可用） |

> 实时接口：`day-reports` / `tasks` / `task` / `users` / `crafts` / `produce-bills` 直接依赖快工单 OpenAPI，网络异常时可能报 500 或空数组。
> 缓存接口：`bills` / `bill-status` / `goods` / `craft-orders` 读本地缓存（`kgd_bill_cache` / `kgd_task_cache` / `kgd_goods_cache`），查询前自动触发一次即时同步（**30 秒节流**：同一 30 秒窗口内只真正同步一次，数据最多延迟 30 秒；首次调用可能稍慢），同步失败时继续返回旧缓存。

## 2. 报工明细

### GET `/api/report-data/day-reports`

按日期获取当日所有报工记录（按 `created_at` 归属日期）。

**Query 参数**

| 参数    | 必填 | 类型     | 说明                                |
| ----- | -- | ------ | --------------------------------- |
| `day` | 是  | string | 日期，格式 `YYYY-MM-DD`，如 `2026-08-12` |

**返回**：`Array<ReportRecord>`

| 字段               | 类型             | 说明                    |
| ---------------- | -------------- | --------------------- |
| `billCode`       | string         | 加工单号                  |
| `craftName`      | string         | 工序名称                  |
| `goodsName`      | string         | 商品名称                  |
| `goodsStandard`  | string         | 商品规格                  |
| `deliveryDate`   | string \| null | 交期（`YYYY-MM-DD`，可能为空） |
| `htNo`           | string \| null | 扩展字段「HT图号」            |
| `reportUserName` | string         | 报工人姓名                 |
| `validNum`       | string         | 良品数量                  |
| `wasteNum`       | string         | 不良数量                  |
| `reportNum`      | string         | 报工数量                  |
| `workingMinutes` | number         | 工时（分钟）                |
| `priceModeName`  | string         | 单价模式名称                |

**示例**

```
GET /api/report-data/day-reports?day=2026-08-12
```

```powershell
Invoke-RestMethod -Uri "http://localhost:3001/api/report-data/day-reports?day=2026-08-12" `
  -Headers @{ "X-API-Key" = "7aa6aa6cacc3c3574873f1c5f95b001e4094ebfe2bcce36ac71553ade1385c74" }
```

```json
[
  {
    "billCode": "20260801-001",
    "craftName": "激光下料",
    "goodsName": "石墨板",
    "goodsStandard": "500x500x20",
    "deliveryDate": "2026-08-15",
    "htNo": "HT2026-0100",
    "reportUserName": "张三",
    "validNum": "80",
    "wasteNum": "2",
    "reportNum": "82",
    "workingMinutes": 120,
    "priceModeName": "按工时"
  }
]
```

> 说明：报工接口无时间戳字段，本接口按 `day` 拼接 `created_at` 时间窗口实时拉取，每日数据不可缓存、必须实时请求。

## 4. 任务详情（合并）

### GET `/api/report-data/task`

按「加工单号 + 工序名称」精确查询，多任务并存时合并数量并按优先级取状态（进行中 > 已完成 > 其他）。

**Query 参数**

| 参数      | 必填 | 类型     | 说明                |
| ------- | -- | ------ | ----------------- |
| `code`  | 是  | string | 加工单号，**需 URL 编码** |
| `craft` | 是  | string | 工序名称，**需 URL 编码** |

**返回**：`TaskDetail \| null`（查无返回 `null`）

| 字段                      | 类型     | 说明               |
| ----------------------- | ------ | ---------------- |
| `num`                   | number | 计划数（合并求和）        |
| `valid_num`             | number | 良品数（合并求和）        |
| `waste_num`             | number | 不良数（合并求和）        |
| `status_name`           | string | 状态名称（按优先级取最高的）   |
| `ht`                    | string | HT图号（多值用「、」连接）   |
| `produce_line_names`    | string | 生产线（多值去重合并）      |
| `reportable_user_names` | string | 可报工人（多值去重合并）     |
| `delivery_date`         | string | 交期（`YYYY-MM-DD`） |

**示例**

```
GET /api/report-data/task?code=20260801-001&craft=%E6%BF%80%E5%85%89%E4%B8%8B%E6%96%99
```

```powershell
$code = [uri]::EscapeDataString("20260801-001")
$craft = [uri]::EscapeDataString("激光下料")
$url = "http://localhost:3001/api/report-data/task?code=$code&craft=$craft"
Invoke-RestMethod -Uri $url -Headers @{ "X-API-Key" = "7aa6aa6cacc3c3574873f1c5f95b001e4094ebfe2bcce36ac71553ade1385c74" }
```

```json
{
  "num": 100,
  "valid_num": 80,
  "waste_num": 2,
  "status_name": "进行中",
  "ht": "HT2026-0100",
  "produce_line_names": "一号线",
  "reportable_user_names": "张三、李四",
  "delivery_date": "2026-08-15"
}
```

> 注意：`code` / `craft` 含中文或特殊字符时必须做 `encodeURIComponent` 编码，否则可能匹配失败。

## 6. 加工单交期

### GET `/api/report-data/bills`

按加工单号批量查询交期映射。读本地缓存，查询前自动触发一次即时同步（保证尽量新鲜）。

**Query 参数**

| 参数      | 必填 | 类型     | 说明                      |
| ------- | -- | ------ | ----------------------- |
| `codes` | 是  | string | 加工单号，逗号分隔传多个。为空时返回 `{}` |

**返回**：`Record<string, string>`，`{ 加工单号: "YYYY-MM-DD" }`（未查到或无交期的单不出现在结果中）

**示例**

```
GET /api/report-data/bills?codes=20260801-001,20260802-002
```

```json
{
  "20260801-001": "2026-08-15",
  "20260802-002": "2026-08-18"
}
```

> 注意：`codes` 中应使用 URL 编码后的加工单号（含 `-` 等字符时建议编码）。

## 7. 加工单进行状态

### GET `/api/report-data/bill-status`

获取加工单列表 + 整单状态 + 逐工序进度链。读本地缓存，查询前自动触发一次即时同步。按交期从早到晚排序，无交期排最后。

**Query 参数**：无

**返回**：`Array<BillStatus>`

| 字段              | 类型             | 说明                                  |
| --------------- | -------------- | ----------------------------------- |
| `code`          | string         | 加工单号                                |
| `htNo`          | string         | HT图号                                |
| `goodsName`     | string         | 商品名称                                |
| `goodsSpec`     | string         | 商品规格                                |
| `num`           | string         | 计划数                                 |
| `unitName`      | string         | 单位名称                                |
| `status`        | number         | 加工单状态：`1`=未开始、`2`=进行中、`3`=完成、`4`=取消、`5`=已暂停 |
| `statusName`    | string         | 状态名称                                |
| `deliveryDate`  | string \| null | 交期（`YYYY-MM-DD`）                    |
| `craftProgress` | array          | 工序进度链（同单按工艺顺序排列）                    |

`craftProgress[]` 每项：

| 字段           | 类型     | 说明                          |
| ------------ | ------ | --------------------------- |
| `craftName`  | string | 工序名称                        |
| `status`     | number | 任务状态码（1 未开始 / 2 进行中 / 3 完成） |
| `statusName` | string | 状态名称                        |
| `percent`    | number | 完成百分比 = (良品+不良)/计划数，封顶 100  |
| `num`        | number | 计划数                         |
| `validNum`   | number | 良品数                         |
| `wasteNum`   | number | 不良数                         |

**示例**

```
GET /api/report-data/bill-status
```

```json
[
  {
    "code": "20260801-001",
    "htNo": "HT2026-0100",
    "goodsName": "石墨板",
    "goodsSpec": "500x500x20",
    "num": "100",
    "unitName": "件",
    "status": 2,
    "statusName": "进行中",
    "deliveryDate": "2026-08-15",
    "craftProgress": [
      { "craftName": "激光下料", "status": 2, "statusName": "进行中", "percent": 82, "num": 100, "validNum": 80, "wasteNum": 2 },
      { "craftName": "精加工", "status": 1, "statusName": "未开始", "percent": 0, "num": 100, "validNum": 0, "wasteNum": 0 }
    ]
  }
]
```

> 渲染约定（插件侧）：`status=1`（未开始）展示「未编程」；`status=2` 起逐工序展示进度 chip（percent / 良品 / 计划）。
> 注意：本接口全量返回所有加工单（含已完成/已取消的历史单），渲染成图片时建议只取 `status ∈ {1, 2}` 的行，避免单图超高度上限。

## 8. 商品列表

### GET `/api/report-data/goods`

商品列表（**读本地缓存 `kgd_goods_cache`**，由同步服务滚动拉取快工单 `/open_api/goods/list` 写入；查询后后台触发一次即时同步（30 秒节流），缓存为空时实时拉取兜底），支持关键字过滤与扩展字段透传。

**Query 参数**

| 参数 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `keyword` | 否 | string | 关键字，按商品名/编号/规格/扩展字段值模糊查询（本地过滤）。省略返回全部 |
| `updatedAtStart` | 否 | string | 更新时间起，格式 `YYYY-MM-DD HH:mm:ss`（空格需 URL 编码为 `%20`） |
| `updatedAtEnd` | 否 | string | 更新时间止，格式 `YYYY-MM-DD HH:mm:ss`（空格需 URL 编码为 `%20`） |
| `supplierName` | 否 | string | 供应商名称模糊查询（读缓存 `raw.supplier.name`） |
| `createUserName` | 否 | string | 创建人名称模糊查询（读缓存 `raw.createUser.real_name`） |
| `categoryName` | 否 | string | 商品分类名称模糊查询（读缓存 `categoryPathNames`） |
| `source` | 否 | integer | 商品来源：1=自产，2=外协加工，3=外购 |
| `isEnable` | 否 | integer | 是否启用：1=启用，2=未启用（不传为全部） |

> 提示：以上筛选均为**本地模糊匹配**，与快工单服务端精确匹配行为不同；`keyword` 还覆盖商品扩展字段（如 HT图号）。

**返回**：`Array<Goods>`

| 字段                  | 类型             | 说明                                                                   |
| ------------------- | -------------- | -------------------------------------------------------------------- |
| `id`                | number         | 商品 ID                                                                |
| `code`              | string         | 商品编号                                                                 |
| `name`              | string         | 商品名称                                                                 |
| `standard`          | string         | 规格                                                                   |
| `categoryPathNames` | string         | 分类路径                                                                 |
| `source`            | number         | 来源                                                                   |
| `sourceName`        | string         | 来源名称                                                                 |
| `unitName`          | string         | 单位名称                                                                 |
| `updatedAt`         | string \| null | 更新时间                                                                 |
| `fieldValueList`    | array          | 扩展字段数组，`[{ name, value }]`（如 `[{ "name": "HT图号", "value": "..." }]`） |
| `fieldValues`       | object         | 扩展字段 key-value 映射，可直接 `fieldValues['HT图号']` 取值                       |

**示例**

```
GET /api/report-data/goods?keyword=%E7%9F%B3%E5%A2%A8
```

```powershell
$kw = [uri]::EscapeDataString("石墨")
Invoke-RestMethod -Uri "http://localhost:3001/api/report-data/goods?keyword=$kw" `
  -Headers @{ "X-API-Key" = "7aa6aa6cacc3c3574873f1c5f95b001e4094ebfe2bcce36ac71553ade1385c74" }
```

```json
[
  {
    "id": 12345,
```

#### POST `/api/report-data/upload`

## 15. 注意事项汇总

1. **鉴权**：所有请求必须带 `X-API-Key` 头，缺失或不匹配返回 401（HTTP 标准错误体，非 `{success}` 包装）。
2. **实时 vs 缓存**：`day-reports` / `tasks` / `task` / `users` / `crafts` / `produce-bills` 实时拉取快工单 OpenAPI；`bills` / `bill-status` / `goods` / `craft-orders` 读本地缓存（`kgd_bill_cache` / `kgd_task_cache` / `kgd_goods_cache`），查询前触发即时同步（**30 秒节流**，同步失败回退旧缓存）。
3. **URL 编码**：`task` 的 `code` / `craft`、`goods` 的 `keyword`、`craft-orders` 的 `code` 含中文时务必编码。
4. **多值参数**：`tasks?status=1,2`、`bills?codes=a,b`、`craft-orders?code=a,b` 用英文逗号分隔。
5. **日期格式**：`day` 严格为 `YYYY-MM-DD`。
6. **数据上限**：实时拉取单接口上限 10000 条（分页 100 条/页、并发 6）。
7. **渲染注意**：`bill-status` 全量返回，图片渲染时建议过滤 `status ∈ {1,2}` 防超 Chrome 单图高度上限。
8. **写操作谨慎**：`bill` / `goods/add` / `goods/edit` / `produce-bills/add` / `produce-bills/status` / `tasks/status` / `crafts/add` / `crafts/edit` / `customer_contract/add` 以及第 13 节「OpenAPI 全量透传映射」中的 `reports/add`、`reports/edit`、`customer/add`、`supplier/add`、`else-stock-out/add`、`else-stock-in/add`、`produce-stock-in/add`、`contract/add`、`contract/edit`、`upload` 均为写操作，会真实修改/创建快工单数据；字段校验失败时返回 500 + 快工单错误信息。商品新增/编辑成功后会自动后台刷新商品缓存（30 秒节流）。
9. **已暂停加工单**：快工单加工单状态 `5`=已暂停（任务状态不随之改变，仍可能显示为未开始/进行中，查询时注意结合 `bill-status` 过滤）。
